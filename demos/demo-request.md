# Binance Crypto Research Agent Demo

## User Request

Find a cryptocurrency with strong smart money inflow and analyze:

1. Market ranking and current trend.
2. Smart money inflow.
3. Basic token information.
4. Security and audit risks.
5. Available trading signals.

## Expected Output

A structured research report containing:

- Selected cryptocurrency
- Market trend
- Smart money analysis
- Token information
- Security risks
- Trading signals
- Final risk assessment
