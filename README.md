# Binance Crypto Research Agent

AI agent untuk melakukan riset cryptocurrency menggunakan Binance Skills.

## Capabilities

Agent ini dapat:

1. Mencari token berdasarkan market ranking.
2. Menganalisis smart money inflow.
3. Mengambil informasi token.
4. Melakukan audit keamanan token.
5. Menganalisis sinyal trading.
6. Membandingkan kandidat cryptocurrency.
7. Membuat laporan riset terstruktur.

## Installed Binance Skills

- crypto-market-rank
- smart-money-inflow
- query-token-info
- query-token-audit
- binance-trading-signal

## Example Request

Find a cryptocurrency with strong smart money inflow and analyze:

- Market trend
- Token information
- Security risks
- Trading signals

Generate a final research report with:

1. Token overview
2. Market ranking
3. Smart money activity
4. Security analysis
5. Trading signals
6. Risk assessment
7. Final conclusion

## Agent Workflow

The agent follows this process:

1. Search market ranking data.
2. Identify tokens with strong smart money inflow.
3. Select relevant candidates.
4. Retrieve token information.
5. Perform security and risk analysis.
6. Check available trading signals.
7. Generate a structured research report.
